# Weather App

A weather search tool that fetches current weather data for a city and displays the result through a simple frontend interface.

## Features

- Searches weather information by city name.
- Uses the OpenWeather API to fetch live temperature and weather status.
- Displays feedback for loading states and missing cities.
- Good practice project for API calls and async JavaScript.

## Tech Stack

- HTML
- CSS
- JavaScript
- OpenWeather API

## Getting Started

- Clone or download this repository.
- Open index.html in your browser, or run the folder with VS Code Live Server.


## Notes

- The current implementation includes an API key directly in script.js; move it to a safer setup before public production use.
- Internet access is required because the app fetches live weather data.
